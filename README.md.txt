# Nike Sales Analytics

## Project Overview
This project focuses on cleaning, analyzing, and visualizing Nike sales data using Python and Pandas.

The analysis explores:
- Product performance
- Profit trends
- Regional sales analysis
- Monthly and daily sales patterns
- Data cleaning and preprocessing

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Key Insights
- LeBron 20 generated the highest total profit.
- Kolkata was the highest profit-generating region.
- Sunday generated the highest profit among weekdays.
- November generated the highest monthly profit.

## Project Structure
- `data/` → raw dataset
- `notebooks/` → Jupyter notebooks
- `images/` → charts and screenshots
